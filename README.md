## Опис проєкту

Проєкт містить AI-агента для VS Code Copilot, який готує кросплатформний Python-проєкт Hello World із віртуальним середовищем, скриптами запуску, тестами pytest і CI на GitHub Actions для Windows, Linux та macOS.

## Запуск агента

1. Відкрий папку репозиторію у VS Code.
2. Відкрий Copilot Chat.
3. Вибери агента `build-engineer`.
4. Виконай команду `/init`.

## Commands

- `/git-init` — перевірити або ініціалізувати Git і налаштувати `.gitignore`.
- `/create-project` — створити початкову структуру Python-проєкту.
- `/create-build` — налаштувати pytest, скрипти запуску та CI-скрипти.
- `/create-actions` — створити GitHub Actions workflow для Windows, Linux і macOS.
- `/check` — перевірити файли, тести, запуск, CI та Git-ігнорування.
- `/init` — послідовно виконати початкове налаштування й перевірки проєкту.
